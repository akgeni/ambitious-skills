# Ambition Altitude

Elevate tasks from immediate tactical execution to systemic outcomes and durable automation.

## When to Use

- User asks to fulfill an administrative, business, or recurring deliverable (e.g., decks, reports, summaries).
- User is fixing isolated issues (e.g., individual bugs, data cleanup) rather than addressing root systems.
- User wants to design workflows that remove human-in-the-loop bottlenecks.

## Principles

- **Find the Goal Beyond the Goal:** Identify what decision, behavior, or systemic shift needs to happen after the task is delivered. Do not stop at the deliverable itself.
- **Feed Raw Context:** Provide full operational context and data rather than constrained templates. Let the model see the broader business landscape.
- **Design the Replacement System:** Transform static periodic checkpoints (e.g., quarterly reviews) into continuous, automated detection mechanisms with historical validation.

## Workflow

1. **Clarify the Core Objective:**
   - Ask: "What decision or action must happen once this is completed?"
   - Reframe the deliverable from a static asset into a decision vehicle.

2. **Ascend the Abstraction Ladder:**
   - Level 1 (Tactical): Execute the immediate task (e.g., fill the slide template).
   - Level 2 (Strategic): Analyze underlying causes and propose the top 3 urgent decisions with trade-offs.
   - Level 3 (Systemic): Design a continuous mechanism or automated loop that renders the manual task obsolete.

3. **Deliver at Highest Feasible Altitude:**
   - Present the strategic implications and decisions first.
   - Outline the systemic automation requirements (data connectors, verification loops, execution environment).

## Gotchas

- Do not jump to pure abstraction if the user strictly needs an immediate tactical artifact. Provide both the immediate answer and the systemic upgrade.
- High altitude requires rich input data. If context is missing, specify what raw access is needed.
